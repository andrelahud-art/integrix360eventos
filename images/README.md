# Carpeta de Imágenes

Esta carpeta contiene las imágenes de los inflables que se muestran en la landing page.

## 📸 Cómo Agregar Imágenes

### Imagen del Castillo (CONFIGURADA)

La imagen del Inflable Castillo ya está configurada en el HTML.

**Para que se muestre correctamente:**

1. Guarda tu foto del castillo como: `castillo.jpg`
2. Colócala en esta carpeta (`images/`)
3. ¡Listo! La imagen se mostrará automáticamente

### Imágenes Pendientes

Para agregar las imágenes de los otros inflables, sigue el mismo proceso:

**Inflable Unicornio:**
- Nombre del archivo: `unicornio.jpg`
- Ubicación: `images/unicornio.jpg`

**Inflable Mario Bros:**
- Nombre del archivo: `mario-bros.jpg`
- Ubicación: `images/mario-bros.jpg`

**Inflable Resbaladilla:**
- Nombre del archivo: `resbaladilla.jpg`
- Ubicación: `images/resbaladilla.jpg`

## 📐 Especificaciones Recomendadas

Para mejores resultados:

- **Formato:** JPG o WebP (WebP es más ligero)
- **Dimensiones mínimas:** 800x600 píxeles
- **Relación de aspecto:** 4:3 o similar
- **Peso:** Menos de 500KB por imagen (optimiza antes de subir)
- **Calidad:** Alta resolución, bien iluminadas, fondo limpio

## 🛠️ Herramientas de Optimización

Optimiza tus imágenes antes de subirlas para mejorar la velocidad de carga:

- **Online:** [TinyJPG](https://tinyjpg.com/) - Gratis y fácil
- **Online:** [Squoosh](https://squoosh.app/) - De Google, convierte a WebP
- **App:** Photoshop, GIMP, Canva
